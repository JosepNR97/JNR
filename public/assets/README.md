# 🖼️ Organización de recursos gráficos

Los recursos visuales de la interfaz se almacenan localmente en esta carpeta. Mantén nombres descriptivos, en minúsculas y separados por guiones, y referencia siempre los archivos mediante `assetPath()`.

Antes de incorporar una imagen, comprueba que tenga permiso de uso, un formato válido y un tamaño adecuado para web.
